### 2.3 75aa2869: the cut trace keeps one sample per sample step (G-SIMMEM)

| Cell | Column | ad9b6c13 | 75aa2869 |
|---|---|---|---|
| Scallop / TaperedBallNose / softwood | `power_peak_kw` | 0.0689 | 0.0739 (+7.3 %) |
| Scallop / TaperedBallNose / hardwood | `power_peak_kw` | 0.1155 | 0.1238 (+7.2 %) |

The commit message names the air-cut % and the per-sample radial on
subdivided moves. It does not name the power peak. The code explains it:
a merged sample keeps the maximum arc (`sample_coalesce.rs:230`) and the
time-weighted mean axial DOC (`:243`), and `tool_load::power::sample_power_kw`
multiplies the two. When the maximum arc and the deeper subsegment are
different subsegments, the merged sample reads above every subsegment it
replaces. The Scallop on the dome has Z-subdivided moves; the 2D cells
have none, so only these two cells move.

## 3. The golden gate

`crates/rs_cam_core/tests/feeds_matrix_instrument_fm1.rs` is now a gate.
The pattern is `crates/rs_cam_viz/tests/mcp_wire_surface_pin.rs`.

| Test | Compares | Runtime (2026-09-30) | Runs in |
|---|---|---|---|
| `the_feeds_matrix_is_the_committed_csv_fm1` | 960 cells, `matrix_2026-09-23.csv` | 0.2 s | every run of the binary |
| `the_sim_subset_is_the_committed_csv_fm1` | 38 rows, `matrix_2026-09-23_sim.csv` | 144-149 s | `--features heavy-tests` (the core full gate); ignored without it |

- A failure prints one line per cell: operation / tool / diameter /
  material, the column, `committed -> now`, and a count per column.
- Every column is compared as the CSV prints it (4 decimals on a number).
  There is no extra tolerance.
- `RS_CAM_UPDATE_FEEDS_MATRIX=1` rewrites the files and fails on purpose.
  The simulation test also rewrites `MATRIX_SUMMARY.md`, which the gate
  does not compare (it prints the wall-clock).
- Rule (in `src/feeds/CLAUDE.md`): a feeds change re-blesses the files in
  the same commit and names the moved cells in its commit message.

Two changes make the subset deterministic:

1. `elapsed_s` is removed from the CSV. The wall-clock is in the summary
   only.
2. A fixed list (`sim_left_out`) replaces the 150 s wall-clock budget. The
   list holds the three cells the budget skipped on every recorded run:
   DropCutter / BallNose / hardwood and DropCutter / TaperedBallNose /
   softwood and hardwood. The budget was not deterministic: at a59b246b
   on this machine it ran DropCutter / BallNose / hardwood (63.1 s), and at
   head it skipped the same cell.

Determinism: three runs at head (the first run, the re-bless and the
green run) give the same values, and the 07777325 run gives the committed
rows.
