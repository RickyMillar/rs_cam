# 2026-06-04 baseline — Phase 5 Step 5.4 (per-species wood Kc from FPL Ch.5)

## What changed in the code

`Material::SolidWood::kc_n_per_mm2()` per-species values updated from
folklore constants to FPL-GTR-190 Ch.5 Table 5-3a shear-parallel-to-
grain values (12% MC). Per-species mapping table (with verbatim FPL
row quotes) is in `wood_kc_derivation.md`.

Per-species Kc shifts in `crates/rs_cam_core/src/material.rs`:

| Variant | Old (folklore) | New (FPL-cited) | Δ % |
|---|---:|---:|---:|
| GenericSoftwood | 6.0 | 6.5 | +8% |
| RadiataPine | 6.0 | 6.0 | 0% (not in FPL) |
| LongleafPine | 7.0 | 10.4 | +48% |
| GenericHardwood | 14.0 | 13.0 | -7% |
| HardMaple | 15.0 | 16.0 | +7% |
| Walnut | 12.0 | 9.5 | -21% |
| Birch | 13.0 | 13.0 | 0% |
| WhiteOak | 14.0 | 13.8 | -1% |
| Jarrah | 19.0 | 19.0 | 0% (not in FPL) |
| Ipe | 28.0 | 28.0 | 0% (not in FPL) |

**Scope deferral:** Values remain in the FPL shear-parallel-to-grain
magnitude regime (6–28 N/mm²). A "true" peripheral milling Kc
would multiply by a 3–5× edge-radius size-effect factor, but
applying it requires a coordinated anisotropy-factor retune
(analogous to Phase 2B for sheet goods) and bench validation.
That work is Phase 6+ scope. What Step 5.4 buys: every value ties
back to a specific FPL row with verbatim citation; the folklore
TODO closes.

## Test sites that needed adjustment

Two lib-level tests pinned to the folklore Kc were updated:

- `tool_load::deflection::tests::small_engraver_low_feed_in_hardwood_passes`:
  reduced axial sample 0.3 → 0.2 mm. The test was tuned to land at
  ~197 µm under HardMaple Kc=15.0 (just under the 200 µm bound);
  the new Kc=16.0 pushes it to ~210 µm. A genuinely-light engraver
  cut at the new Kc is ~0.2 mm axial.
- `tool_load::power::tests::vbit_triangular_cross_section_halves_power_vs_flat`:
  hand-computed `expected` updated from `30.0 · 0.5 · ...` to
  `32.0 · 0.5 · ...` to reflect HardMaple Kc 16.0 (was 15.0). Same
  test intent, new constant.

## Why this is the right baseline

The 2026-06-03 baseline's deflection values were physically
calibrated against folklore Kc constants. The 2026-06-04 values
are calibrated against FPL Ch.5 shear-parallel-to-grain — the
literature anchor that the codebase had documented as the
"intended source" since Phase 2B's TODO marker. Step 5.4 closes
that TODO; the deflection magnitudes shift by the small Kc deltas
above.
