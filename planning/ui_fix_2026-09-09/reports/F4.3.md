## 1. What an operator could do before: nothing

A project opens, one model file is not where the project says it is. The
session loads with a placeholder — `mesh: None`, `load_error: Some(reason)` —
and the operator's options were:

| Route | Why it did not help |
|---|---|
| Reload from disk | Re-imports **the same path that just failed**. |
| Delete | Refused while any toolpath references the model — i.e. exactly when it matters. |
| Re-point the Input combo | Moves an operation to a *different* model; does not repair this one, and there is no other model to move to. |
| Read the reason | `load_error` was rendered **nowhere** in the GUI. Only MCP `inspect_model` published it. |

So a project copied to another machine, or a project folder moved on this one,
had **no repair route in the UI at all**. R0.7 §2.3 has the full table; I
re-verified each row against this checkout before changing anything.

Three defects underneath, and they are separable:

1. **No browse-for-a-new-path action.** `rg "LocateModel|SetModelPath|RelinkModel"`
   returned nothing.
2. **The in-memory path was the raw string from the file.** The project loader
   computed a resolved path for the READ and threw it away
   (`load_model_geometry`), storing `PathBuf::from(&model_section.path)`. So a
   project saying `path = "m.stl"` kept a path that resolves against the
   **process working directory** — Reload looked for `./m.stl` wherever
   `rs_cam_gui` was launched, and the warning printed a string that named no
   directory anyone had searched.
3. **The save was a pass-through.** `to_project_file` wrote
   `m.path.to_string_lossy()` verbatim, so whether a project survived being
   moved depended on how its models were first added.

## 4. The lead's caution 2 — a relink is a geometry change, and the id does not move

This is the important one, and it decides which instrument is correct.

`generation_inputs_signature` (F2.1) includes `model_id`. That is what catches
an operator re-pointing an operation's **Input** combo: the id changes, the
signature moves, `invalidate_toolpath_inputs` fires. **A relink changes
nothing that signature can see.** Same model id, same operation, same
dressups, same heights — and completely different geometry. The signature
comparison is blind to it by construction.

`invalidate_model(model_id)` keys on the **id** rather than on a signature,
which is exactly why it is the right instrument here: it drops the cached
result of every toolpath naming that model, and — because it goes through
`drop_result` — bumps each one's `toolpath_revision`, so F2.4's late-result
guard covers a generation that was already in flight when the operator
relinked. The GUI sweep then requests regeneration, matching `reload_model`.

`missing_model_relink_g_modelrelink` asserts the id is unchanged **and** that
the results are gone, in that order, so the pair cannot be read as "it worked
because the id changed".

**One deliberate difference from my first draft.** The GUI sweep sets
`stale_since` but does **not** clear `rt.result`. Clearing it made the
operation read `NoResult` — "never generated" — which is false and throws away
the F2.2 vocabulary (`STALE` chip, dimmed path, `old:` figures) that exists
precisely to say "this was generated and is now out of date". Keeping it
matches `reload_model` and F2.4's stored-not-discarded doctrine. The sentry
pins `EditedSince`, not `NoResult`, so the distinction cannot be lost again.

## 5. Decisions taken on R0.7's open questions

R0.7 §7 left six questions. The operator has not answered them; I took R0.7's
own recommendation in each case and am recording that these are assumptions.

| Q | Decision | Why |
|---|---|---|
| 1. Different kind → refuse or allow? | **Refuse**, with a notification naming the Input control as the right tool. | A relink means "this file moved". A mesh operation cannot run on polygons, so allowing it would produce a project whose every toolpath is unrunnable — and the Input combo already exists for "use a different model". |
| 2. Refit stock on relink? | **Not implemented.** | `reload_model` does not refit either, and doing it here would make relink and reload differ. R0.7 recommends yes *via a shared helper that also changes Reload*; that refactor is not in this row. Ledgered. |
| 3. Button on healthy models too? | **Yes.** | Pointing a model at a different file is the same operation whether or not the old one is still there, and hiding it would make the repair route discoverable only in the failure it repairs. |
| 4. Type the warning list? | **No.** Pruned by the model-name prefix. | Typing `load_warnings` reaches `controller.rs`, `app.rs`, `app/mcp.rs` and the harness — a refactor with its own risk, inside a repair task. The string prefix is ugly and it is honest about being ugly. Ledgered. |
| 5. MCP `inspect_model.path` becomes absolute | **Accepted.** | It is the same value every other consumer now sees, and the previous value was a string that resolved against the GUI's working directory — not more useful, just less true. |
| 6. Windows cross-drive → absolute | **Accepted.** | `strip_prefix` fails across drives and the rule falls through to absolute, which is correct. |

### Two gates caught real defects in this task's own code

Recording these because a gate that catches the author is the gate working.

1. **`clippy::clone_on_ref_ptr` / `redundant_clone`** on the geometry swap: I
   had copied `reload_model`'s `.clone()` calls, but `relinked` is this
   function's own import and is dropped immediately after, so the fields are
   now MOVED. `reload_model` clones for no better reason; not changed here,
   because that is F4.4's refactor.
2. **`ui_string_hygiene::no_operator_string_carries_a_collapsed_line_continuation`**
   — both new operator strings (the Locate-file hover and the kind refusal)
   were written as `\`-continued literals, and `cargo fmt` collapsed each onto
   one line **keeping the continuation indentation**, so they would have
   shipped with 14-space holes in the middle of a sentence. Rewritten as
   single literals. That sentry did exactly the job F1.15 was about — an
   operator-facing sentence arriving damaged — and it caught it before a human
   ever saw the panel.

  not in this row.
