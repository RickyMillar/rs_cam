## Goal

Each physical rule has the G-CENTRECUT shape: fact → predicate → plan clamp → generation outcome
→ simulation measure → export → sentry. One `physical_rules!` row per rule names every stage, so a
rule cannot skip one. One feasibility stage after `run_stages` reads the emitted toolpath, the
tool facts (K3) and the stock box, and gives a typed `FeasibilityReport`. Every outcome is a
warning (Q6): the program never refuses a job. A stage value is `Clamp`, `Model`, `Measure`,
`Warn` or `None`; no `Refuse` value exists, so this phase cannot write a refusal. The plan-stage
clamp still avoids the danger where it can. The warning names the fact and how it is known (Q7):
"flute 25 mm, Estimated: hole 30 mm".

   - This check needs no mesh, so op 3 (DXF model) is caught.

     is. Do not change its 0.01 mm strike limit or the band skip at `collision.rs:441` in this
     phase: they move collision counts (`the_machine_head_guards_the_checks_h1`).

7. **VTipFlat.**
   - Fact: `v_tip_diameter` on a `VBit`. Plan (Model): `build_cutter` (`compute/cutter.rs:12`,
     V arm `:32-37@40cf411a7`) sets `VBitEndmill::tip_diameter` (`tool/vbit.rs:62@40cf411a7`,

     writes the same tip, so `geometry_hint_matches_the_built_cutter` stays true.
   - Gen: warn when the tip is `Unknown` on a V op (VCarve, Inlay, Inlay Plug, Trace, Chamfer,
     Project Curve with a V-bit), and when the cone height of the stated tip disagrees with
     `cutting_length`. Report 06 (a2) and C 1.3 give the case: the V20 record has
     `cutting_length = 8.152467616`, which is the cone height of a 0.3 mm flat, while the sharp cone
     is 9.003 mm. Compute both in the test from the formula `(d/2 - tip/2) / tan(half angle)`.
