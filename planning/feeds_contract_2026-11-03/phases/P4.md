# P4: Every op states its cut (`CutSpec`, today's calculator basis)

Status: NOT STARTED | Contracts: K1 | Rulings: Q2, Q4 (they act in Phase 5; P4 only builds the type) | Numbers move: no. FM1, the op goldens and the G-code stay identical.

## Goal

After this phase, each op builds one `CutSpec` from its own config: the radial cut, the axial
cut, the total depth and what the first pass meets. Each registry row states its `CutRule` in
place of `feeds_hints: FeedsHints::NONE`. Suggest gets its three calculator inputs from the
`CutSpec` through one projection that gives today's values for each op, so every FM1 cell stays
identical. `FeedsHints` and its `Default` are gone.

## Changes

1. **The value types.**
   - What: add `CutSpec`, `Radial`, `Axial`, `TotalDepth`, `FirstPass`, `Stated<T>` and `Mm` in
     a new file `compute/catalog/cut_spec.rs`.
   - Where: beside `compute/catalog/capabilities.rs`; re-export from `compute/catalog.rs` as the
     other catalog types are (`catalog.rs:26`).
   - How:
     ```rust
     /// CONTRACT K1. Built only by `OperationConfig::cut_spec` (exhaustive, no wildcard).
     /// No `Default` on any type in this file.
     #[derive(Debug, Clone, Copy, PartialEq)]
     pub struct CutSpec { pub radial: Radial, pub axial: Axial, pub total: TotalDepth, pub first_pass: FirstPass }
     /// An operator value. The constructor is `pub(in crate::compute)`: Suggest
     /// (`feeds/`) cannot make one. It stores the f64 bit for bit (no rounding).
     #[derive(Debug, Clone, Copy, PartialEq)]
     pub struct Stated<T>(T);
     #[derive(Debug, Clone, Copy, PartialEq)]
     pub struct Mm(f64);
     pub enum Radial {
         Width(Stated<Mm>),          // stepover the operator set
         Slot,                       // ae = D
         Groove,                     // V ops: width follows depth (D2: no tool angle here)
         Scallop(Stated<Mm>),        // finishing: width from the scallop target
         AngularStep(Stated<f64>),   // Radial Finish, degrees (D2: addition)
         SurfaceFollow,              // the surface sets the width
         Axial,                      // Drill, Pin Drill: no radial cut
     }
     pub enum Axial {
         PerPass(Stated<Mm>),
         ZStep(Stated<Mm>),
         OnePass(Option<Stated<Mm>>),   // None = S11 unset
         Peck(Stated<Mm>),
         HelixPitch(Stated<Mm>),        // Bore (D2: addition)
         ChamferWidth(Stated<Mm>),      // Chamfer (D2: addition)
         Surface { max: Option<Stated<Mm>> },
     }
     pub enum TotalDepth { Known(Stated<Mm>), FromHeights, Unset, None(&'static str) }
     pub enum FirstPass { Slot, NotSlot }   // D1
     ```
   - Callers: new code; 0 at HEAD.

2. **The row rule.**
   - What: replace `Capabilities::feeds_hints: FeedsHints` with `cut_rule: CutRule`; delete
     `FeedsHints`, `FeedsHints::NONE` and its `Default` derive.
   - Where: `compute/catalog/capabilities.rs:72-75@40cf411a7` (field), `:317`
     (`with_entry_probe` names it); `compute/catalog.rs:1910-1931@40cf411a7` `FeedsHints`; the 25
     row lines in Appendix A.
   - How:
     ```rust
     /// CONTRACT K1 (row half). No `Default`, no `NONE` constant: each `REG_*`
     /// literal names every field.
     #[derive(Debug, Clone, Copy, PartialEq, Eq)]
     pub struct CutRule { pub radial: RadialRule, pub axial: AxialRule, pub calc_reads: PresentBasis }
     pub enum RadialRule { Stepover, Slot, Groove, Scallop, ScallopElseStepover,
                           OffsetStepoverElseSurface, AngularStep, SurfaceFollow, NoRadial }
     pub enum AxialRule { DepthPerPass, ZStep, OnePass, Peck, HelixPitch, ChamferWidth,
                          Surface, SurfaceCapped }
     /// P4 migration marker: what the calculator reads today. Phase 5 deletes it.
     pub enum PresentBasis { FamilyDefault, AxialFromSpec, ScallopFromSpec }
     ```
     This is how the row forces a new op to state its cut. `Capabilities` has no `Default`
     (`capabilities.rs:41`), no row uses `..` (A 1.3), and `with_entry_probe` names every field
     (`capabilities.rs:308-340`). So a new `REG_*` literal does not compile without
     `cut_rule:`, and `CutRule` gives it no shorthand. The row holds a RULE, never a number
     (the `Capabilities<P>` precedent, `capabilities.rs:37-38`).
   - Callers: `rg -n "FeedsHints" crates --type rust` = 48 hits in 5 files;
     `rg -n "feeds_hints" crates --type rust` = 54 hits in 10 files.

3. **The builder.**
   - What: `OperationConfig::cut_spec(&self) -> CutSpec`, one arm per variant, no wildcard.
   - Where: `compute/catalog.rs`, beside `capabilities()` (`catalog.rs:1006-1123@40cf411a7`).
   - How: each arm reads only its own config fields (Appendix A). Delete the six
     `capabilities()` arms that only set `feeds_hints` (UnifiedFinish, DropCutter, Waterline,

   - Callers: new; `rg -n "\.cut_spec\(" crates` = 0 at HEAD.

4. **Suggest reads the spec, with today's basis.**
   - What: `operation_feeds_hints` keeps its signature and tuple; its body reads the spec.
   - Where: `feeds/suggest/apply.rs:1196-1206@40cf411a7` `operation_feeds_hints`;
     `feeds/suggest/axial_envelope.rs:184` (reads `capabilities().feeds_hints.axial_depth_mm`;
     switch to `operation_feeds_hints(op).0`). `feeds/suggest.rs:996` and
     `aggressiveness.rs:202` already call the tuple adapter.
   - How:
     ```rust
     impl CutSpec {
         /// P4 only: today's three calculator inputs. Phase 5 deletes it.
         pub(crate) fn todays_hints(&self, reads: PresentBasis) -> (Option<f64>, Option<f64>, Option<f64>) {
             match reads {
                 PresentBasis::FamilyDefault => (None, None, None),
                 PresentBasis::AxialFromSpec => (self.axial.stated_mm(), None, None),
                 PresentBasis::ScallopFromSpec => (None, None, self.radial.scallop_mm()),

     }
     ```
     `Axial::stated_mm` and `Radial::scallop_mm` are exhaustive matches. The radial slot stays
     `None` for every op (A 1.4: no op sends a radial width today).
   - Callers: `rg -n "operation_feeds_hints" crates --type rust` = 11 hits in 5 files (one is
     `tests/literature_matrix/shim.rs:462`); `feeds_input_for_operation` = 34 hits in 15 files,

  and the full row literal already refuse a new op without a cut. A derive hook needs a
