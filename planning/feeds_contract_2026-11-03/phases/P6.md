# P6: Every tool fact states how it is known (`ToolFact<T>`)

Status: DONE 2026-11-04 (commits A, B, C; see the review notes at the end) | Contracts: K3 (feeds K8) | Rulings: Q7, Q9 | Numbers move: no (every
migrated value keeps its number; a new tool added with an omitted fact plans at the old default,
now marked Unknown)

## Goal

Each measured tool fact carries its provenance: `Stated`, `Catalogue`, `Estimated` or `Unknown`.
No code reads a fact as a bare number; the field is private and each reader picks an accessor.
`non_centre_cutting: None` stops meaning "centre cutting": the fact becomes
`ToolFact<CentreCutting>`, and an absent key is `Unknown`. A project or catalogue file with a bare
number refuses to load (Q9); a script migrates every checked-in file in the same commit.
