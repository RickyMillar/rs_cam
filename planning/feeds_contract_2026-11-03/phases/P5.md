## Goal

After this phase, each number that Suggest ships carries a `Basis`. Suggest returns a
`SafeEnvelope`: the limits it computes today and then discards, a speeds map, one proposal and
the placement of the operator's point. `Command::ApplyFeeds` writes the speeds for the geometry
the op keeps. It writes depth, stepover or peck only for an `EnvelopePick`. A score tie between
vendor rows takes the lower chip, and the card and MCP name both rows.

Operator ruling 2026-11-03: the program never refuses a job; every finding is a warning. An
operator value outside the envelope is a warning that names the limit it crosses. The compiler
still refuses code: speeds are applied only for a point that the envelope computed.
