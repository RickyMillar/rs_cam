# rs_cam_core contracts

The feeds contract (`planning/feeds_contract_2026-11-03/PLAN.md`) names the rules that the compiler holds. One line per contract: the rule, the type or setting, the file and the sentry. The detail lives in the folder `CLAUDE.md` that each contract touches, and in `PLAN.md`.

- Lint: no wildcard arm over two or more variants (`Cargo.toml` `wildcard_enum_match_arm` deny; an exception is `#[expect(.., reason)]` on the `let` or the smallest `fn`). Sentry: the full clippy gate.
- K1: every op states its cut. `OperationConfig::cut_spec` builds a `CutSpec` with an exhaustive match; each `REG_*` row states its `CutRule`; no `Default` in `compute/catalog/cut_spec.rs`. Sentries: `--test every_op_states_its_cut_k1`, `--doc cut_spec_refusals`.
- K2: every shipped number names its source. `feeds/sourced.rs`: `Sourced<T>` (no public constructor), `Basis`, the unit newtypes, `lower_to_cap` (`min` only); `apply` takes `Recommendation<Complete>`; every apply door calls `accept_unsourced` (D4) and files `UnsourcedRowsAccepted`. Sentries: `--test suggest_never_raises_a_stated_depth_k2`, `--test a_tie_takes_the_lower_chip_and_names_both_q3`, `--doc sourced_refusals`.
- K2b: Suggest returns a space of safe choices. `feeds/envelope.rs`: `SafeEnvelope::for_cut` (the only constructor); a geometry write needs an `EnvelopePick` from `SafeEnvelope::pick`. Sentries: `--test apply_writes_speeds_unless_a_pick_k2b`, `--test the_envelope_keeps_each_limit_k2b`, `--test a_pick_outside_the_envelope_warns_k2b`, `--doc envelope_refusals`.
- K3: every tool fact states how it is known. `compute/tool_fact.rs`: `ToolFact<T> { Stated, Catalogue, Estimated, Unknown }` (no `Default`, no `Deref`); the `ToolConfig` fact fields are private; a bare value refuses to load; D12: centre cutting and a V tip must be known. Sentries: `--test a_tool_fact_states_how_it_is_known_k3`, `--doc tool_fact`.
- D8: no geometry default without a tool. The tool-derived fields are `Option`; each `REG_*` row states `geometry: &[GeometryDefault]`; `geometry_default::write_rule_values` is the one writer. Sentries: `--test every_geometry_default_is_a_fraction_of_the_tool_d8`, `--test a_tool_change_moves_a_derived_geometry_value_d8`.
- K4: every op states how it enters material. Each `REG_*` row states `entry: EntryContract` (no `Default`), the one entry source (`compute/catalog/entry_contract.rs`); the air lead is `MoveIntent::EntryApproach`. Sentries: `--test every_op_states_its_entry_contract_k4`, `--test an_air_lead_is_an_approach_not_a_plunge_k4`, `--test project_curve_plunges_at_the_axial_chip_q8`, `--doc entry_contract_refusals`, `--lib entry_contract_table_is_pinned`.
- K5: every physical rule has the G-CENTRECUT shape. `compute/feasibility.rs`: one `physical_rules!` row per rule with every `Stage` and its id; `Stage` has no refusing value; each row warns on every surface. Sentries: `--test every_physical_rule_warns_through_a_row_k5`, one `_k5_<rule>` per rule, `--doc feasibility`.
- K6: every finding states its consequence and no finding refuses a job (Q6). Each `diag_ids!` row ends `=> warn(Danger::X)`, `=> INFO` or `=> NOT_READY`; `Consequence` has no refusing arm; only `EmitError` stops a file. Sentries: `--test a_job_with_each_finding_exports_and_names_it_k6`, viz `--test a_job_with_each_finding_exports_and_names_it_on_every_surface_k6`, `--lib every_id_states_its_consequence_k6`, `--doc diag_ids`.
- K7: one engagement before and after the simulation (Q5). `feeds/engagement.rs`: `Engagement` (private fields; `from_cut`, `from_tool_cut`, `from_sample`) is the only builder of `PowerModelInputs`; the deflection readers take the peak of `edge_force`; pre-sim power is the maximum over `PowerCases`; the simulation is placed, not fed back (`compute::simulate::envelope_placement`). Sentries: `--test one_engagement_before_and_after_the_simulation_k7`, `--test pre_sim_power_ships_the_worst_case_k7`, `--test the_simulation_is_placed_not_fed_back_k7`, `--test the_power_curve_picks_the_arm_at_the_feed_cap_q1`, `--doc engagement`.
- K8: every generated toolpath carries its lineage (Q7). `trace/lineage.rs`: `Lineage` (no `Default`) is a required field of `ToolpathComputeResult`, built by `Lineage::of` with no calculator run; `steps` is a view of `FeedsProvenance::steps`. Sentries: `--test every_generated_toolpath_has_a_lineage_k8`, `--test every_calculator_step_leaves_one_record_p13b`, `--test the_step_records_are_stored_and_bounded_p13b`, `--doc lineage`.
