## Invariants

- No background lock: R1 core seeds an EMPTY feed field from Suggest (⚡). W3k: the operator's padlock (core `FeedsLock`, default Chipload) holds one of Feed/Spindle/Chipload; an edit writes the dependent field in the same frame.
- W3i: the Chipload row reads core `AdvancePerToothMm`. The chart and the card read
  `FeedsMemo::preview` / `::card` (F216); the panel host fills the memo on every tab (`refresh_feeds_memo`).
- The apply writes through the core command path (`Command::ApplyFeeds`, F114); the write stales the result.
- The recommended column is what `⚡ Apply all` writes; the hover has the raw value.
- The card is `DataTable` rows (IC2). The face holds one status row per problem (and
  a refusal); the apply buttons, every recipe row, the stages and the basis are in its ONE `Details`.
- Every stage that moves a number is ONE row with its source (ruling R4, in
  `Details`): `why::suggest_rows`, `why::row_basis_rows` (P16 item 8: the "Vendors: .. (ships the lowest)" row reads `FeedsResult::vendor_band()`). A problem is one
  status row on the face (`why::Placement`). P13c: the envelope notes (`SafeEnvelope::notes`, the computed-width assumptions) are a caution on the SAFE CUT header row (`envelope::header`; no added row; the short core face `EnvelopeNote::face` of the first note (P29-10 10b), which fits at 340 points, the core text of every note on hover) and `ComputedWidthAssumptions` a caution stage in Details (the same face and hover); the plot names `LimitKind::CornerCoverage` "Corner width".
- A nomogram readout outside the axes abstains; the hover opens only on the plot. P5d D3, one mark rule on both charts: white dot = the setpoint ⚡ writes (`candidate_speeds` on the nomogram during a draft); hollow `TEXT_MUTED` ghost = the stored value, only during a draft; quiet ACCENT (`recommendation_color`, 1 pt) = the recommendation, never moves. The memo builds the envelope (`FeedsMemo::envelope`); a frame only reads it (F216).
- The nomogram draws one line at the suggested value, and band lines only where the
  row publishes both limits; no shading. The envelope plot paints ONE soft fill of the safe region (operator 2026-11-06); the nomogram keeps lines only.
- Power and the verdict read the cut Apply writes (`power_at_shipped_point`); the power bar is a `Details` row, never a face row (10f: no viz share; it differs from the body power row, see `power_row`).
